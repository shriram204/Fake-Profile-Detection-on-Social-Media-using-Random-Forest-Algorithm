# 🔍 Fake Profile Detection on Social Media using Random Forest Algorithm

## 📌 Project Overview

Fake social media profiles are increasingly used for spreading misinformation, conducting scams, phishing attacks, and manipulating online communities.

This project uses **Machine Learning and the Random Forest Classification Algorithm** to identify fake and genuine social media profiles based on profile attributes and user activity patterns.

The system analyzes different parameters such as profile completeness, followers count, following count, posting frequency, account age, and engagement rate to predict whether a profile is Fake or Genuine.

## 🎯 Objectives

- To detect fake and suspicious social media profiles automatically.
- To analyze user profile attributes and behavioral patterns.
- To implement a Random Forest Classifier for profile classification.
- To improve social media security and user trust.
- To visualize feature importance and model performance.

## 🧠 System Architecture

1. **Data Collection:** Collect profile-related information and behavioral attributes.
2. **Data Preprocessing:** Handle missing values, remove duplicates, and prepare features.
3. **Feature Extraction:** Analyze profile completeness, account age, followers-following ratio, and activity patterns.
4. **Model Training:** Train the Random Forest Classifier using labeled profile data.
5. **Classification:** Predict whether the given profile is Fake or Genuine.
6. **Performance Evaluation:** Evaluate model performance using accuracy, precision, recall, F1-score, and ROC-AUC.
